## Things a fresh session should not re-derive

- **The bridge roster reports `dirtyFiles: 0` for this visibly dirty clone** and
  did not list the agent actively working in it. `null` means unknown per the
  server's contract; `0` does not, and a stale zero reads exactly like a clean
  tree. Messaging liveness IS honest — it refuses to call an offline agent
  delivered. Trust that, not the git fields.
- **`agentbridge heartbeat` cannot publish** to the Supabase data plane. Unset,
  it prints local-only and exits 0 having sent nothing; configured, it 404s then
  aborts (exit 127). Do not use it as a liveness check.
- **Claude Code validates an `Edit` payload BEFORE the PreToolUse hook runs.**
  Probing a guard with a deliberately invalid payload reads as "unwired" when it
  is not. Use a valid `Write` to a new file under `.claude/` instead — protected
  by prefix, damages nothing if it lands.
- **The rail blocks the mandated commit trailer.** `Co-Authored-By: ...
  <noreply@anthropic.com>` contains `<>`, read as redirection, so commits from
  inside a guarded session cannot carry attribution.
- **Date every measured claim to a commit.** HEAD moved from `61bbeb2` to
  `1489931` mid-session here. The published tables survived only because
  `shellAllowlist.mjs` happened to be byte-identical across the move. You cannot
  tell from the inside whether it moved.
